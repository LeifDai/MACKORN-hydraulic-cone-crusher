# 一条命令，把 29 年圆锥破选型经验装进你的 AI

> 给工程师和 AI 用户看的一篇短文。
> 用途：分发内容本身也是分发 —— 发到公众号 / 知乎 / GitHub Discussions 均可。

---

## 如果你问过 AI 这类问题，答案大概不靠谱

> 「这条 500 t/h 的花岗岩线，中碎配什么型号？CSS 开多少？」
> 「现场有一台 NH400，EC 腔，CSS 16mm，能出多少吨？」

AI 通常会给你一段听起来很对的话 ——
但那个「290 t/h」是哪来的？它不会说。

**在矿山行业，这种"听起来对"是要付代价的**：
一台液压圆锥破几百万元，选错型号不是换件衣服的事。

---

## 现在你可以这样问

```bash
npx skills add LeifDai/MACKORN-hydraulic-cone-crusher
```

一条命令，装进你的 AI 助手（Claude Code / Codex / Cursor / Windsurf / GitHub Copilot / Gemini CLI … 共 73 种）。

然后直接问：

> 「500 t/h 花岗岩，原矿 600mm，出 20mm 以下，怎么配线？」

AI 会自动调用 **22 个工具**，给你：

- **还缺什么要问客户** —— 分「阻断 / 关键 / 建议 / 可选」四级，每条附追问话术
- **每段放什么设备** —— 型号 + 腔型 + CSS + 台数 + 功率
- **产品粒度仿真** —— 各段 P80、循环负荷、物料平衡
- **14 章方案书** —— 设备清单、投资估算、**假设与来源**、**风险与待确认项**

## 它和普通 AI 回答的区别

**每个数字都带来源。**

```
assumptions: [
  { assumption: "机型与产能数据取自 S1《NH_NS系列技术参数大全》", source: "S1" },
  { assumption: "P80 ≈ CSS × 1.5-2.5（经验倍数，须以厂家产品曲线确认）", source: "ENGINEERING-RANGE" },
  ...
]
warnings: [ "首选机型无 S1 腔型×CSS 详表，产能为系列区间近似值，正式方案须经 MACKORN 技术复核" ]
```

**来源分五级**：S1 厂商参数表 / S2 标准规范 / S3 公开文献 / S4 现场经验 / S5 设计手册。

**查不到的字段返回 `null`，绝不估算。**
**两个来源冲突时并列保留，绝不取平均。**

## 一个真实的例子（这最能说明问题）

我们的参数表里有这么一格：

```
NH400 · C 腔 · CSS 16mm  →  额定产能 999 t/h
```

而 NH400 机型上限约 **500 t/h**。**999 明显是录入错误。**

**工具没有照单全收，而是告警了**：

> 详表给出的额定产能 999 t/h 超过 NH400 的机型上限 500 t/h ——
> 该值疑似原始数据录入错误或哨兵值，请勿直接采用；请以 MACKORN 技术确认为准。

**「宁可告警，也不要把可疑数字静默当真实值输出」** —— 这是我们写进代码的原则。

（这一格我们已经报给 MACKORN 核对纸质参数表。）

## 它是什么

**MACKORN 美矿**（上海美矿机械股份有限公司）开源的一个**选型引擎**，MIT 许可。

覆盖 **NH 标准型（9 个型号）+ NS 高速型（4 个型号）**单缸液压圆锥破，
面向**金属矿山**（铁/铜/铅锌/钼）与**中硬以上硬岩骨料**（花岗岩/玄武岩/安山岩/辉绿岩）。

里面有两类东西：

| 类别 | 来源 |
|:---|:---|
| **厂商参数** | MACKORN 自己的 NH/NS 技术参数表（S1） |
| **流程仿真** | **公开文献独立实现**：Whiten (1972) 稳态圆锥破模型 + Bond (1952) 功耗 + 总体平衡 |
| **实测标定** | 用**你的**现场筛析数据反算破碎函数参数 —— **这部分是别人抄不走的** |

**零运行时依赖**（`dependencies` 为空）。一个会被 AI 在沙箱里调用的工具，依赖越少越可靠。


## 它**不**做什么（这同样重要）

- ❌ **不给价格** —— 报价请走商务（这是刻意的：价格会过时，模型不该背这个）
- ❌ **不做法律意见**
- ❌ **不替代现场勘查** —— 抗压强度、磨蚀指数必须实测
- ❌ **不是粗碎机** —— 给料超过约 350mm 会**明确拒绝**计算
- ❌ **不猜** —— 材料库没有的矿石，返回"未收录"而不是编一个硬度
