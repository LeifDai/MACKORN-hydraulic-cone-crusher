## §4 🎯 Bruno 数据库挖掘（重大发现）

**Bruno 是 Bruno3 破碎流程仿真软件的 MDB 数据库**（8.5MB），已提取为 JSON（14MB）。

### 可用的表
```
[  17 行] MATERIAL     17 种国际标准岩石参数（破碎性 + 磨蚀指数）
[ 840 行] CRUSNAME     840 机型（美卓 C 系列颚破 + GP/HP/MP 圆锥破 + Symons + Barmac）
[ 208 行] 圆锥破组合   GP/HP/MP 全系列，每机型 5-8 个腔型
[5000 行] CAPACITY     真实产能（但数据质量可疑，见下）
[5000 行] POWER        真实功率
```

### MATERIAL 的 17 种真实参数（可用）
```
Amphibolite  ρ=2.83  破碎性=34.0   磨蚀=921.5
Basalt       ρ=2.90  破碎性=25.9   磨蚀=1132
Granite      ρ=2.70  破碎性=35.0   磨蚀=1398
Limestone    ρ=2.60  破碎性=40.0   磨蚀=434
Quartzite    ρ=2.60  破碎性=41.9   磨蚀=1798  ← 最磨蚀
Kimberlite   ρ=2.48  破碎性=60.7   磨蚀=140   ← 最不磨蚀
（共 17 种，含 Diabase/Diorite/Dolomite/Gabbro/Gneiss/Sandstone 等）
```

### ⚠️ 数据质量警告（必须核实）
```
① CAPACITY 表 5000 行里，前 20 个 CrusherId 全是美卓 C 系列颚破（C63/C95/C100...）
   CSS 400-3400mm 完全符合颚破，不是圆锥破

② 圆锥破的 CAPACITY 数据显示 CSS 130-480mm，比标准大 5-10 倍
   GP100 标准 CSS 是 8-40mm，显示 130-240mm
   → 可能是「1/10 mm」单位，或数据口径不同

③ CRUSNAME 的 Motor 字段几乎全是 null

⇒ 结论：Bruno 数据可作为【竞品参数对照参考】，但【不能直接替代】MACKORN 自己的 S1 厂商数据
  必须先用已知机型的标准参数交叉验证 Bruno 的单位与口径
```
