# 📋 磨矿/选矿/自动化 厂商参数待填表（给 MACKORN 技术部）

> 生成：2026-10-20（R120）
> **为什么需要这个**：插件目前破碎段有完整厂商参数（S1 高精度），
> 但磨矿/选矿/自动化三段只有文献区间（S3-S5 中等精度），
> 所以这三个工具在问"具体型号"时会诚实返回 `null`。

> **填完这张表，这三段就能从「文献区间」升级到「厂商参数」，精度质变。**

## 使用说明

```
1. 每一行都有【必填/选填】标记 —— 必填的填不上就先留空，别猜
2. 数值必须写明单位；不确定的写区间（如 800-1200）
3. 每一格都请写【来源】：厂家样本 / 实测 / 经验值 / 标准规范
4. 填完交给 AI，会直接写成 data-grinding-vendor.mjs 等文件并接入工具
★ 铁律：宁可留空，不许猜。填错的数字会让客户买错设备。
```

## 五、填表后的效果（诚实说明）

```
✅ 能得到的提升：
   · 磨矿工具从"推荐方式 + 功率量级"→"推荐具体型号 + 台数"
   · 选矿工具从"方法 + 文献回收率区间"→"设备型号 + 案例回收率"
   · 自动化工具从"通用仪表清单"→"该项目的实际仪表位号表"
   · 整线贯通工具从"量级串联"→"可下采购单的配置"

❌ 仍做不到的（不要期待）：
   · 仍不能替代选矿试验（回收率必须试验）
   · 仍不能替代爆破设计（需民爆资质）
   · 仍不能替代施工图（需设计院出图）
   · 仍不对外报价

★ 一句话：
   填了这张表，插件从"懂工艺的顾问"变成"记得住你所有型号的老工程师"。
   但它仍然不是设计院，也不是试验室。
```
