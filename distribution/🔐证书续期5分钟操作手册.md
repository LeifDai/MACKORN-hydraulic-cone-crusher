## 二、续期方法（三选一，推荐方式 A）

### 方式 A：阿里云控制台重新申请（最稳，5 分钟）

#### 步骤 1：登录阿里云

```
https://www.aliyun.com/  →  登录你的账号
```

#### 步骤 2：进数字证书管理服务

```
控制台 → 搜索「数字证书」→ 数字证书管理服务（原 SSL 证书）
或直接访问：https://yundun.console.aliyun.com/?p=cas
```

#### 步骤 3：申请免费证书

```
左侧菜单 → SSL 证书 → 免费证书 → 「创建证书」

选择：
  · 证书类型：DV 单域名 / 免费证书
  · 域名：填 mackorn.cn       ← 注意：免费证书通常只能绑一个域名
  · 如果不支持多域名，申请两张：
      第 1 张：mackorn.cn
      第 2 张：www.mackorn.cn

★ 阿里云免费证书额度：每年 20 张（个人）/ 企业也有额度
```

#### 步骤 4：域名验证（自动，约 1-3 分钟）

```
选「DNS 验证」或「文件验证」：
  · DNS 验证：阿里云会自动在你的域名下加 TXT 记录（因为域名也在阿里云）
  · 文件验证：需上传一个文件到网站根目录

★ 因为你的域名就在阿里云，选 DNS 验证通常几秒就过
```

#### 步骤 5：下载证书

```
证书签发后 → 点「下载」→ 选「Apache」格式

会得到一个 zip，里面通常有：
  · xxx_public.crt      （证书文件）
  · xxx.key             （私钥）
  · xxx_chain.crt       （证书链）
```

#### 步骤 6：上传到服务器并替换

```
服务器：47.110.80.123
站点根目录（从之前记录看）：/usr/home/hyu8030010001/htdocs/

① SSH 登录（⚠️ 我测试 22 端口从本机不通，需要用阿里云控制台的「远程连接」）
   阿里云控制台 → ECS → 实例 → 远程连接 → Workbench / VNC

② 上传三个文件到服务器，例如：
   /usr/home/hyu8030010001/htdocs/ssl/

③ 找到 Apache 配置里的 SSL 配置段：
   可能是：/etc/httpd/conf.d/ssl.conf
           /etc/apache2/vhosts.d/*.conf
           /etc/httpd/conf/httpd.conf
   
   搜关键词：SSLCertificateFile

④ 把三行改成新文件路径：
   SSLCertificateFile      /usr/home/hyu8030010001/htdocs/ssl/xxx_public.crt
   SSLCertificateKeyFile   /usr/home/hyu8030010001/htdocs/ssl/xxx.key
   SSLCertificateChainFile /usr/home/hyu8030010001/htdocs/ssl/xxx_chain.crt

⑤ 重启 Apache：
   systemctl restart httpd
   或   systemctl restart apache2
   或   service httpd restart
```

### 方式 C：用 certbot（如果服务器已有）

