   但部署结构是 官网落地页/ → /ai/，应该写 官网落地页/videos/
   → 教训：建文件前先看部署目录结构

   · xlsxwriter 报 '_get_xf_index'（格式对象传参错误）
   · openpyxl 的 valign 合法值是 center，不是 vcenter
   → 教训：两个库的 API 不通用，别混着写

③ 规则六里用 await import 在非 async 函数
   → 改成直接 import statSync
   → 教训：ESM 模块里 require 和顶层 await 都要小心
