### 它做了什么

```
耦合三个已发表模型：
  ① Whiten 分类-破碎群体平衡   → 产品粒度分布   ← 我们用的同一个
  ② Evertsson 流量能力模型     → throughput hump ← 我们没有！
  ③ Bond 定律                  → 功率           ← 我们用的同一个

支持机型：cone / jaw / gyratory
可调参数：eccentric speed, throw, closed-side setting, feed

诚实声明：耦合的是"标定过的模型"，不是真实产线；
         3D 腔型视图是运动学动画，不是真 DEM 求解
```

## 四、辩证对照：我们与 ChancaDEM 的关系

### 正题：它对我们的三个价值

```
① 交叉验证基准
   我们的 plugin/lib/simulate.mjs 也是 Whiten 实现。
   同样的 CSS / throw / feed，如果两边 P80 差异 > 20%，
   说明至少一方实现有问题 —— 这是难得的独立对照物。

② 补 Evertsson 流量模型
   我们现在只有 Whiten（粒度分布）+ Bond（功率），
   【没有 throughput hump 模型】。ChancaDEM 有。
   这是我们可以借鉴的明确缺口。

③ 可引用的第三方来源
   CC-BY + MIT，可以合法引用、对照、写进假设来源。
```

### 反题：它不能替代我们（最强反驳自己的"有竞品了"）

```
① 定位完全不同
   ChancaDEM = 物理演示台（browser studio，看"为什么"）
   我们      = 选型工程工具（从客户需求表到 14 章方案书）

② 它没有的东西（每一条都是我们的护城河）
   · MACKORN NH/NS 厂商真实参数（S1）
   · 腔型 × CSS 产能详表
   · 材料库（14 种矿石的性质区间）
   · 客户需求表 → 缺失项追问 → 方案书
   · 经销商评估、市场纵深、成本估算
   · 12 语言、Agent Skills、MCP 服务器
   · 中文界面与中文行业术语

③ 它是 0 star 的新项目
   不是"权威"，也不是市场威胁 —— 但它确实是同一技术路线的独立实现。
```

### 合题：正确的关系是「参照物」不是「竞品」

```
ChancaDEM 不能替代我们，
但它可以当一个【外部标尺】：
  · 我们的 Whiten 实现对不对？跟它对一遍
  · 我们缺的 Evertsson 流量模型，它有
  · 它的弱点正好证明我们的垂直化方向是对的

→ 结论：引用它、对照它、借它的 Evertsson，
  但继续走"垂直行业 + 厂商数据 + 商业闭环"的路。
```

### 可证伪：什么现象会说明我这个判断错了

```
如果出现以下任一情况，说明我低估了它：
  · 它开始收录具体厂商机型参数（进入我们的领域）
  · 它被美卓/山特维克等厂商官方采用
  · 它积累 > 500 stars 且有商业用户
  · 它提供了我们没有的【实测标定数据集】

目前（2026-10-19）：0 star、无厂商数据、无实测数据集 → 判断成立。
```
