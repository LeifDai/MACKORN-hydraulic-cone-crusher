### probe.php 的安全特性（SW0001.2）

```
① Token 存文件（_probe/.token），不落源码 → GitHub 泄漏免疫
② hash_equals 常量时间比对 → 防时序攻击
③ 支持 Authorization: Bearer
④ 目录 0700 / 文件 0600
⑤ _probe/.htaccess 双保险
⑥ SSL 校验强制开启（VERIFYPEER=true + VERIFYHOST=2）→ 防 MITM
⑦ action=init / migrate / rotate / run / get / status / help
```

### 为什么用 probe.php 而不是 Node/PM2/GitHub Actions

| 方案 | IT 难度 | 稳定性 | 结论 |
|:---|:---|:---|:---:|
| GitHub Actions | 中 | ❌ Nightly 连续 3 次失败 | 现状坏 |
| 阿里云装 Node+PM2 | 高（SSH+安装+维护） | 中（重启会挂） | 做不了 |
| **probe.php + cron** | **极低（传 1 个文件）** | **高（PHP 本来在跑）** | **🏆 最优** |

```

   父进程是 explorer，天然脱离任何终端/沙箱
```
