```js

  '以下为 MACKORN 内部历史参考价格区间（来源 S4），实际报价以最新商务确认为准；
   汇率、钢材价、电压等级、液压站配置、交货条件均会显著影响最终价格。';

- **本质是"参考"不是"报价"**

## 六、附带发现：一个更深的问题

**我们的门禁一直在跑"合规零命中"，但没抓到这个问题。**

为什么？

```
build_public.mjs 查的是：
  · 本地绝对路径
  · 客户名
  · 密钥/凭据
  · 版本号一致性

它没查：**对外承诺 与 实际行为 是否一致**
```

**这是门禁的盲区**：我们检查"文件干不干净"，但没检查"说的话和做的事对不对得上"。

## 七、建议新增的门禁（G13）

```
检查「对外承诺」与「实际行为」的一致性：

① 扫 README / llms.txt 里的承诺句（"no pricing" / "zero dependencies" / "offline" 等）

③ 不一致 → 红

这一条能抓住今天这个问题，也能抓住未来类似的「说一套做一套」。
