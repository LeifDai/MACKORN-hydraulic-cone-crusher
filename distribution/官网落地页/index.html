它能做什么

把"老师傅的手艺"变成 AI 能直接调用的 22 个工具。

① 还缺什么要问客户

客户表里没填、但必须问的字段，按阻断 / 关键 / 建议 / 可选四级列出，每条带追问话术与"为什么必须要"。

② 该配什么设备

分几段、各段粒度怎么分、圆锥破机型 + 腔型 + 排矿口 CSS + 台数 + 功率、粗碎选什么、筛分面积、皮带带宽、辅机清单。

③ 产品粒度能算

用 Whiten(1972) 稳态模型算产品 P20/P50/P80、破碎比、啮合区；Bond(1952) 估算吨电耗。

④ 整线流程仿真

多段破碎 + 筛分 + 闭路：各段 P80、循环负荷、最终出料、物料平衡校核（出料率须 = 1）。

⑤ 用你自己的数据标定

输入现场筛析数据，反算破碎函数参数，把文献模型换成你自己的设备模型，附拟合优度与逐点残差。

⑥ 直接出方案书

14 章完整方案书：设备清单、投资估算、假设与数据来源、风险与待确认项、附件清单。

一句话：从"客户要一条 600 t/h 的线"直接走到"每段放什么设备、多大 CSS、几台、出料多细、循环负荷多少、成本多少"。

数据可信度 —— 这是它和"随便一个 AI 插件"的区别

选型这件事，AI 最容易犯三种错：编参数、漏流程、把经验值当标定值。

机制做法
数据分级每条数据标注为 厂商硬数据 / 厂商历史资料 / 工程经验区间 / 空缺 四级
输出带证每个工具输出都带 assumptions[]（假设 + 来源）与 warnings[]（告警）
缺口不编查不到的字段返回 null 并进告警；多来源冲突并列保留，不取平均
参数来源可查仿真输出标明参数来自 MACKORN-实测标定、LITERATURE 还是 USER
边界告警标定参数若贴在搜索边界，会明确告警"未被数据约束住"，不给出看似漂亮的拟合
负控自检8 项负控——故意造坏必须响亮报错。只有负控响过，"干净日志"才算证据
明确说明局限：NH600 及以上机型暂无腔型 × CSS 详表，产能为系列区间外推，结论标注"系列区间近似"须技术复核； 循环负荷系数与筛分效率的厂家标定值缺失，现用工程经验区间； 除铁器/除尘器价格、安装调试金额、全系列偏心距、CE 认证信息不在知识库内，返回 null。 本工具不替代现场踏勘、物料试验与商务确认。

常见问题

液压圆锥破碎机选型用什么工具？

用 MACKORN 美矿开源的 AI 选型插件。输入一张客户需求表和一个目标产量，输出：还缺什么要问客户、该配什么设备（机型 / 腔型 / 排矿口 CSS / 台数 / 功率）、整线配置、产品粒度仿真、循环负荷，以及一份 14 章方案书。22 个工具，零运行时依赖，MIT 开源，任何 AI 均可调用。

圆锥破排矿口 CSS 怎么定？产品粒度能算出来吗？

可以。内置 Whiten(1972) 稳态圆锥破模型，输入给料粒度与紧边排矿口 CSS，即可算出产品 P20/P50/P80、破碎比与啮合区 K1/K2；再用 Bond(1952) 估算吨电耗。

循环负荷怎么算？

用群体平衡迭代求解闭路稳态：逐段计算产品曲线、把筛上循环料回代，直到收敛。物料平衡按绝对质量推进（新鲜料 = 1），确保守恒。输出循环负荷比、各段 P80、最终出料粒度与出料率（须等于 1.000000）。

数据来源可靠吗？会不会编数字？

厂商参数来自 MACKORN 自有 NH/NS 产品数据；过程仿真使用公开发表文献，完全独立实现，不含任何第三方专有数据。工程经验值一律标注为区间，绝不冒充标定值。查不到的字段返回 null 并进告警，不编造。

支持哪些 AI？

任何支持 MCP（Model Context Protocol）的客户端：Claude、ChatGPT、Gemini、Grok、Cursor、VS Code、Cline 等；DeepSeek Harness 通过插件市场安装。

适用物料与目标市场 / Materials & Markets

Metal mines (medium-hard and above) — iron ore, copper ore, lead-zinc ore, molybdenum ore, gold, chromium. Hard-rock aggregate — granite, basalt, andesite, diabase. These are exactly the feeds where a single-cylinder hydraulic cone crusher earns its keep: high compressive strength, abrasive, and unforgiving of a badly chosen cavity or closed-side setting.

金属矿山（中硬以上） —— 铁矿、铜矿、铅锌矿、钼矿、金矿、铬矿。 硬岩骨料 —— 花岗岩、玄武岩、安山岩、辉绿岩。这类物料抗压强度高、磨蚀性强， 腔型与排矿口选错代价很大——正是单缸液压圆锥破的价值所在。
