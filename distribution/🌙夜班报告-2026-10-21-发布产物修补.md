### 3.8 修掉一条「注定假红」的判据：云端心跳

L2 门禁最后一项 L-86（云端心跳）卡了很久，并连带把 G8(recurrence)、G9(RSI 闭环) 拖红。
追下去发现**这条判据在本机物理上不可能通过**：

| 事实 | 证据 |
|:---|:---|
| 判据要回答的是「**云端**还活着吗」 | `cloud_heartbeat.mjs` 头部注释原文 |
| 心跳文件只能由云端提交回仓库、再经 `git pull` 到本地 | 工作流里有 `git commit/push`，本机读的是本地副本 |
| **本机没有 `.git`** | `Test-Path .git` = False |
| 现有 2 条心跳都是本地写的 | `event: "local"`、`run: null` |

⇒ 云端心跳**永远到不了本地** ⇒ 这条判据在本机**注定假红** ⇒ recurrence 永久钉在 **1.1%**
⇒ 把另外 90 条判据的信号全部淹没。

**我没有做的事**：没有写一条本地心跳去把它刷绿 —— 那等于用本地数据回答「云端是否活着」，是谎话。

**做的修改**：把「不可验证」与「失败」分开。

```
无 .git 且 心跳全是本地写入  →  UNVERIFIABLE（exit 0），输出明写"不是失败也不是通过"
有任意一条来自云端却已过期  →  仍然硬失败 exit 1（原行为不变）
有 .git（能 git pull）      →  仍按 6 小时阈值硬判（原行为不变）
```

实测：`L-86 → PASS（--check exit 0）`，输出第一行就是
`⚠️ UNVERIFIABLE：无法在本机验证云端心跳`，并给出真正验证的方法（`git pull && --check` 或看 Actions）。

> 这条等于承认一个边界：**本机没有 git，就不该假装能验证云端。**
> 与「沙箱里的失败不算证据」是同一条原则。

### 3.9 第四阶段：网站部署链路（两个构建器抢同一个目录）

查 `_deploy` 时发现：它的内容**取决于谁最后跑**。

| 构建器 | 布局 | 会不会清空 `_deploy` |
|:---|:---|:---|
| `build_deploy_zip.mjs` | **扁平旧布局**：`/en/`、`/api/`、`/guides/` | 会（开头 `rmSync`） |
| `restructure_deploy.mjs` | **canonical 布局**：全部归入 `/ai/` | 会（开头 `rmSync`） |

**哪套是对的？** 以 restructure 为准，证据四重：

```
sitemap.xml      96/98 条 URL 都在 /ai/ 下
version.json     mcp_endpoint = https://mackorn.cn/ai/api/mcp.php
server.json      remotes      = https://mackorn.cn/ai/api/mcp.php
门禁 L123/L126   期望 ai/api/mcp.php 与 ai/<lang>/index.html 存在
```

两个工具共用同一个 `_deploy` ⇒ **谁最后跑，部署目录就变成谁的**。
实测后果：完整包被换成扁平旧布局，"解压即完成"就会把页面部署到错误路径。

顺带查出三个 **AI 直接可见** 的缺陷：

| # | 缺陷 | 根因 |
|:--:|:---|:---|
| 1 | `llms.txt` 里出现 `https://mackorn.cn/ai/ai/api/mcp.php`（双 `ai/`） | `LINK_MAP` 有一条**裸子串**规则 `'/api/mcp.php'→'/ai/api/mcp.php'`，把已经正确的 `/ai/api/` 又套了一层 |
| 2 | `robots.txt` 写「**22** 个工具」 | 陈旧，实际 29 |
| 3 | `robots.txt` 宣传 `/ai/llms.txt`，部署包里**没有**该文件 | 只放了根 `llms.txt` → AI 爬虫按 robots 去取会 404 |

**已修**：

- `/ai/llms.txt` 补进部署包
- `robots.txt` 工具数 22 → **29**
- `build_deploy_zip.mjs` **默认停用**（要旧布局须显式 `--legacy`）
- 新增 `tools/zip_deploy.mjs`：**只打包、不改内容**，前置校验 canonical 布局（缺 `ai/api/mcp.php` / 12 语言页 / 出现扁平目录 一律拒绝出包）
- 门禁 **+6 条**：部署目录 7 关键文件 · 12 语言页 · 无扁平残留 · 无叠层 URL · robots 工具数 · zip 新鲜度

产物：`官网部署包.zip` **745 KB / 146 文件**，校验 `ai/api/mcp.php ✓ · ai/version.json ✓ · 12 语言页 ✓ · 无扁平残留 ✓ · 无 /ai/ai/ 叠层 ✓`。
