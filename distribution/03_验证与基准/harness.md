## 一、五条硬规矩（不可违反）

| # | 规矩 | 怎么做 | 为什么 |
|:--|:---|:---|:---|
| HR-1 | **绝不编造数字** | 未知字段返回 null | 一个编造的"200mm"会让客户买错设备；一个诚实的 null 只会让客户多问一句 |
| HR-2 | **每个结论必须带来源** | S1 厂商 / S2 标准 / S3 文献 / S4 经验 / S5 手册 | 没有来源的数字不该进代码 |
| HR-3 | **冲突数据并列保留，绝不取平均** | conflict[] 数组，不做数值合并 | 取平均会把一个明确的矛盾变成看不见的错误 |
| HR-4 | **承认边界** | 液压圆锥破给料 > 350mm 必须拒绝 | 它不是粗碎机，硬算会给出误导结果 |
| HR-5 | **不信任自我报告** | 必须真跑门禁，不能信"应该没问题" | 本会话多次出现"工具自报成功但实际失败" |
