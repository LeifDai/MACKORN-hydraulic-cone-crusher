## 二、每个环节能回答什么

### ① 采矿 `mackorn_mining_interface`

```
输入：target_tph, max_feed_mm, rock_type, stripping_ratio, haul_km, muddy
输出：
  · 采矿工序链（剥离 / 钻孔爆破 / 铲装 / 短倒短驳）
  · ★ Kuz-Ram 爆破块度预测（算爆堆 P50/P80/P90）
  · ★ 爆破块度对粗碎选型的影响（最关键接口）
  · 剥采比要点
  · ★ 运输能力校核（破碎机吃不饱最常见原因是运输跟不上）

负控：
  · 含泥/黏土夹层 → 强制提示预筛分除土（不能靠爆破解决）
  · 剥采比 >5 → 告警核算经济性
  · 原矿块度 >1000mm → 告警需大型颚破/旋回破 + 二次破碎

诚实边界：不含爆破设计与审批（需民爆资质）、不含开采设计（需资质）
         Kuz-Ram 经验模型误差 ±20-30%，岩石系数 A 必须现场标定

实测：Kuz-Ram 算例 A=10 V=120 Q=45 → X50=45.2cm / P80=97.2cm
```

### ③ 磨矿 `mackorn_grinding_selection`

```
输入：target_tph, feed_p80_mm, product_p80_mm, ore, closed_circuit
输出：
  · 磨矿方式推荐（SAG / 球磨 / HPGR）
  · 装机功率量级 + 比能耗区间
  · 分级设备（螺旋分级机 / 水力旋流器）
  · 候选排序

负控：
  · 给料 >350mm → 拒绝（磨机吃不下，先破碎）
  · 目标 P80 <20μm → 告警过磨区
  · 半自磨 <300t/d → 告警不经济
  · 螺旋分级机用于 <74μm → 建议改旋流器

诚实边界：【不含厂商型号参数】（MQY/MQS 等），只给方式+功率量级
         型号建议恒返回 null，明确写需厂家功率曲线

实测：10000 t/h → SAG（60000-160000 kW）；1000 t/h → 球磨（8000-25000 kW）
```

### ④ 选矿 `mackorn_beneficiation_selection`

```
输入：ore, target_mineral, liberation_um, feed_p80_mm, target_tph, slime_pct
输出：
  · 方法推荐（浮选 / 重选 / 光电选 / 磁选）
  · 预期回收率区间（浮选 80-95% / 重选 70-92% / 磁选 80-95%）
  · 适用粒度、能耗、限制
  · 光电选的 5 种传感器（激光/图像/XRT/XRF/NIR）
  · 指标定义（回收率/精矿品位/选比/尾矿品位/精矿产率）

负控：
  · 解离 <10μm → 告警（常规浮选效率急降，需专门研究）
  · 解离 >200μm → 告警（粗粒浮选回收率低）
  · 矿泥 >15% → 强制提示脱泥
  · 无矿石类型 → 拒绝（不瞎猜）
  · ★ 光电选抛废率必须做工业试验，禁止把经验区间写进投资决策

诚实边界：不含药剂制度（企业机密）、不含浮选动力学、不含设备型号、不含经济指标
```

### ⑤ 自动化 `mackorn_automation_design`

```
输入：section, target_tph, has_plc, has_scada, has_online_analyzer, has_dedicated_staff
输出：
  · 自动化分层建议（L0 现场层 / L1 PLC / L2 DCS-SCADA / L3 先进控制）
  · 关键仪表清单（破碎 6 / 磨矿 7 / 选矿 6，标注哪些关键）
  · 控制回路（给料量 / CSS / 磨机负荷 / 浓度 / 旋流器压力 / 联锁）
  · 电气驱动要点（高压vs低压 / 变频适用 / 软启动 / 过铁硬线联锁 / 谐波）
  · ★ L3 就绪条件判定（5 条）

负控：
  · 无 PLC → 明确判定「绝不能上 L3」（沙地上盖楼）
  · 无 SCADA → 告警补 L2
  · 无在线分析 → 告警模型缺关键输入
  · 无专职维护 → 明确不建议上 L3（MPC 通常 6-12 个月后失效）

诚实边界：不含 PLC/DCS 品牌组态、不含 PID 整定值（必须现场调试）、
         不含仪表型号量程、不含电气单线图、不含报价
```

## 四、诚实清单：全链条贯通 ≠ 全能

```
✅ 做到：五段都有知识库 + 引擎 + 工具 + 负控 + 诚实边界
❌ 没做到：
   · 磨矿/选矿/自动化【没有厂商型号参数】—— 需 MACKORN 提供
   · 磨矿/选矿/自动化【没有经济指标】—— 本项目不对外报价
   · 采矿【不含爆破设计与开采设计】—— 需民爆/采矿设计资质
   · 全链条【没有端到端串起来的单一工具】—— 现在要靠 5 个工具分别问
   · 缺 P6「整线贯通」：从爆破参数一路算到精矿指标

★ 最重要的诚实：
   「五段都有工具」不等于「五段都有厂商级精度」。
   破碎段有 S1 厂商参数，其余三段是 S3/S5 文献区间。
   用户问磨矿具体型号时，工具会诚实返回 null + 说明需厂家资料 —— 这是设计意图，不是缺陷。
```

## 五、P6 整线贯通（已完成）

**`mackorn_full_chain`** —— 一次调用串完五段：

```
输入：target_tph, max_feed_mm, target_product_mm, ore, to_beneficiation, liberation_um
输出：
  · 物料水线（如 原矿 800mm → 粗碎 200mm → 中碎 50mm → 细碎 10mm）
  · 每段明细（工序名 / 来源等级 / 关键输出）
  · ★ 最弱环节标注（整线可信度受它限制）
  · 台数爆炸告警

实测（1000 t/h 砂石骨料）：
  水线 800→200→50→10mm
  中碎 NH860/EC · 500kW · 3台
  细碎 NH300/F · 160kW · 20台 ← 触发台数爆炸告警
  最弱环节：采矿·爆破块度（S3 经验模型）

★ 关键设计：每段都标来源等级
  S1（厂商参数）→ 破碎段，高精度
  S3/S5（文献）→ 磨矿/选矿，中等精度
  ENGINEERING-RANGE → 粗碎估算
  所以整线可信度 = min(各段)
```

**已知缺口（诚实）**：
```
· 粗碎段没有独立选型引擎（本插件只做圆锥破）
· 磨矿/选矿段没有厂商型号参数
· 段间未考虑循环负荷放大（闭路时上游需 1.2-1.3 倍）
· 未做设备台数的全局最优组合优化
· 未含土建/电气/总图/投资估算
```
