## §1 🔴 Q6 卡 3 天的真因（AGENTS.md 教训 #6）

```
R208 的合并逻辑假设 _data_materials.php 返回 { MATERIAL_LIBRARY: [...] }（嵌套）
实际文件返回 [ '花岗岩' => [...], '玄武岩' => [...] ]（直接数组）
→ foreach 把「花岗岩」当成顶层键 → $DB['MATERIAL_LIBRARY'] 仍空
```

**改法**：
```php
// 错的（假设嵌套）
$M = include '_data_materials.php';
$DB['MATERIAL_LIBRARY'] = $M['MATERIAL_LIBRARY'];

// 对的（直接数组）
$M = include '_data_materials.php';
if (is_array($M)) {
    foreach ($M as $k => $v) {
        if (!isset($DB[$k]) || (is_array($DB[$k]) && count($DB[$k]) === 0)) {
            $DB[$k] = $v;
        }
    }
}
```

**规则**：任何 include/merge 之前先 `var_dump` 或写端到端模拟验证结构。
