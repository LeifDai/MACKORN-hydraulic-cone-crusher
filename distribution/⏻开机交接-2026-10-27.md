## §5 今晚学到的两条硬教训

### ① 「工具报不可用」先怀疑工具，不要先怀疑环境

```
沙箱 EPERM：spawnSync + {encoding:'utf8'} 捕获子进程 stdout
→ 不抛异常，只是 stdout=undefined
→ 业务代码误判「服务不可用」
→ 六层分工里 L3（本地）和 L2（免费云）两层被同时关掉好几天没人发现

正确写法：
  · 查 HTTP 服务 → 直接用 fetch（不起子进程）
  · 必须起子进程 → shell:true + 整条命令字符串 + 重定向到文件 + 读文件
```

### ② 文档里的版本号必须与磁盘一致

```
AGENTS.md 说 V001.5.1 是唯一真相（64.8KB，41 条自测）
实际磁盘只有 econ-router.mjs（58.5KB，selftest 4/5 可用）

后果：新人按文档跑 `node tools/econ-router-V001.5.1.mjs --selftest`
     → MODULE_NOT_FOUND → 以为整个 econ-router 坏了

判据：文档里出现的每个文件路径，必须在磁盘上存在。
     建议加一条门禁：扫描 AGENTS.md 里所有 tools/xxx.mjs，逐个 existsSync。
```
