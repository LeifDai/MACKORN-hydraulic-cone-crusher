### `free_router.mjs` 修了用户初版的 4 个坑

```
① apiKey 不写默认假值
   初版：process.env.X || "你的智谱Key" → 拿假字符串请求 → 401 看起来像 key 失效

   初版：只探 /models 通了就试 → Ollama 起来但没模型会白等 30s

③ 加 --test 模式
   初版只能 import 调用，没法确认降级链真在工作
   改：逐档实测 + 专门的降级链验证

④ 加敏感内容闸
   合同/报价/客户名一律只准本地，本地不可用就抛错拒绝上云
```

## §6 已知未修的 bug（明天做）

### ① `free_router` 的 400 不触发 fallback

```
现象：故意用不存在的主模型 → 智谱返回 HTTP 400 → 直接失败，没降级
原因：fallback 只在「抛异常」时触发，400 被当成「请求完成」
影响：小（实际模型都存在），但逻辑不严谨
修法：非 2xx 且有 fallbackModel → 也试 fallback
```

### ② 环境变量读不到注册表（新进程）

```
现象：setx 写进注册表后，新起的 node 进程读不到
原因：进程启动时的环境变量快照不包含新写入的
修法：free_router / listing_engine 启动时从注册表补读（用 shell:true 重定向，见 AGENTS.md §12）
```
