## 0. 这个插件是什么 / 不是什么

| 是 | 不是 |
|:---|:---|
| 22 个可被 AI 调用的工具（MCP） | ❌ 商业选型软件（如 Bruno）的替代品 |
| 公开文献模型（Whiten 1972 / Bond 1952）的独立实现 | ❌ 厂商标定过的专有模型 |
| 有误差区间与已知局限披露的估算工具 | ❌ 可以直接拿去订货的规格书 |
| 12 语言站点 + 可复现的验证基准 | ❌ 一个黑箱 |

**一句话**：它是**能算、能查、能自曝局限**的工程助手；**不是**精度承诺。

## 2. 标准调用顺序（选型场景）

```
① mackorn_requirement_intake      ← 先确认输入齐不齐，缺什么问客户
        ↓
② mackorn_cone_selection          ← 单台选型（看 knowledge_check 的腔型冲突提示）
        ↓
③ mackorn_capacity_check          ← 用目标产量复核（务必传 target_tph）
        ↓
④ mackorn_crusher_curve           ← 确认产品粒度与误差区间
        ↓
⑤ mackorn_cost_estimate           ← 成本量级
        ↓
⑥ mackorn_proposal / selection_report  ← 收口成文档
```

**整线场景**：把 ② 换成 `mackorn_plant_design`，其余相同。

**运行诊断场景**（设备已在跑）：
```
mackorn_mcfm_analysis → mackorn_grading_porosity → mackorn_wear_design
```

## 3. 硬约束检查清单（勾选式，任一条不过就别往下走）

```
[ ] 给料最大粒度 ≤ 350 mm？
    └ 圆锥破是中细碎设备。>350mm 会被工具【拒绝】——这是设计边界，不是参数调优问题。
    └ 粗碎请用颚破/旋回破。

[ ] 紧边排矿口 CSS 在机型允许范围内？
    └ 工具会返回 css_range_mm。超范围会被拒。

[ ] 给料粒度与腔型匹配？
    └ 硬料配粗腔 → 工具会在 knowledge_check 里报 conflict。硬料宜偏中细腔。

[ ] 目标产品粒度 ≥ CSS？
    └ 产品 P80 不可能小于 CSS。若客户要求小于 CSS，必须开小 CSS 或换腔型。

[ ] 偏心转速 ≤ 400 rpm？
    └ 公开文献实测：>400 rpm 且给料不受限时会【堵料】。护栏 GR-15 会告警。

[ ] 含水率是否过高？
    └ 含水高会堵腔、筛分效率骤降。材料库有典型区间，但必须问现场实测值。

[ ] 闭路循环负荷是否可接受？
    └ simulate_flowsheet 会给循环负荷。过高说明筛分效率或 CSS 需调整。
```

## 4. 判读口径表（工具返回字段怎么读）

### 4.1 产能校核的 `verdict`
| 字段值 | 含义 | 怎么办 |
|:---|:---|:---|
| `achievable_comfortable` | 余量 ≥15% | 可执行。生产计划按额定值的 80–85% 定 |
| `achievable_tight` | 达标但余量 <15% | 核实现场给料条件，预留降产预案 |
| `not_achievable` | 不达标 | 工具会给 4 条路径（开大 CSS / 提转速 / 并联 / 换机型） |
| 无 verdict | 没传 target_tph | 补传目标产量 |

### 4.2 不确定度的 `confidence_grade`
| 分级 | 区间 | 可用性 |
|:---|:---|:---|
| **A** | ±≤10% | 可用于方案 |
| **B** | ±10–25% | 可用于初步方案（当前默认水平） |
| **C** | ±25–50% | 仅可行性判断 |
| **D** | ±>50% | 只说明量级 |

**关键**：区间宽窄反映**参数不确定度**，不是模型误差。分级 C/D 时不得用于订货规格。

### 4.3 给料模数 MCFM
| 值 | 含义 |
|:---|:---|
| 4.0–4.5 | 工程最优窗口 |
| <4.0 | 给料偏粗，层压不足 |
| >4.5 | 给料偏细，易离析 |

### 4.4 质量守恒自检
每个仿真输出都带 `mass_balance.sum_error`。
**若 > 1e-2，结果不可用** —— 说明数值求解没收敛，应报告而不是照用。

## 5. 常见错误（都是真实踩过的）

| 错误 | 后果 | 正确做法 |
|:---|:---|:---|
| 把**参考价区间**当报价发给客户 | 商务事故 | 参考区间 + 偏差倍数两个口径并列，明确"不构成报价" |
| 用**文献默认参数**直接出方案 | 精度不可靠 | 文献参数来自落重试验，更适磨机；圆锥破必须现场标定 |
| 以为**转速越高产量越高** | 可能堵料 | >400 rpm 会堵料。转速对产量有最优值 |
| 把 `mackorn_capacity_check` 当选型工具 | 它只复核已知机型 | 选新型号用 `mackorn_cone_selection` |
| 忽略 `assumptions[]` | 不知道结论建立在什么假设上 | 每次都要读，尤其是 INTERP（插值）标记的 |
| 材料库查不到就猜 | 违反第一硬规矩 | 查不到返回 null + "来源未提供"，**不猜** |
| 两个来源数字不同就取平均 | 违反第三硬规矩 | 并列保留，标注边界，交人工确认 |
| 把 `null` 换成估算值让输出"看起来完整" | 最严重 | null 就是 null |

## 6. 标定怎么做（把模型变成"你自己的"）

**门槛比想象的低** —— 公开文献结论：**每个试验系列只需第一次试验**即可标定破碎函数。

```
① 同一时刻、同一工况下取：给料筛析 + 产品筛析 + CSS
② mackorn_calibrate（给料 ≥2 点，产品 ≥3 点建议 ≥5）
③ 看 RMSE：<0.06 可用；>0.10 查数据质量（多半不是模型问题）
④ 结果标记为「实测」写入知识库 → 后续选型自动优先用实测值
⑤ 用另一工况数据独立验证（P80 相对误差 <10% 视为通过）
```

**优先标哪个**（真跑敏感度分析）：
```
中碎（CSS 40mm）  → 主导误差是 γ（51.5%）     → 优先标 γ、φ
细碎（CSS 16mm）  → 主导误差是啮合系数（75.9%）→ 优先标啮合系数
超细碎（CSS 8mm） → 主导误差是啮合系数（85.2%）→ 优先标啮合系数
```

详见 `distribution/03_验证与基准/现场标定快速指南.md`。

## 8. 已知局限（照抄模型卡，不美化）

| ID | 局限 | 影响 |
|:---|:---|:---|
| L-SPEED | 转速被简化为分类函数的**线性乘子** | 文献用**压缩比 s/b**建模；本实现对转速的敏感性可能被**高估** |
| L-PARAM-SOURCE | 默认破碎函数参数来自**落重试验** | 落重试验接近磨机单颗粒冲击，不是圆锥破层压破碎 → 默认值只宜做**量级估算** |
| L-NO-CONE-DATA | **缺乏圆锥破现场实测数据的公开对标** | 【绝对预测精度】未经对标。已验证的是内部一致性（质量守恒/单调性/确定性）与分布形式 |
| L-NO-DYNAMICS | 只做**稳态** | 启动、堵料瞬态、给料波动、衬板磨损演化都不在范围内 |
| L-SPEED-LIMIT | 转速 >400 rpm 会堵料 | 已加护栏 GR-15 告警 |

完整模型卡：`https://mackorn.cn/ai/model-card/`

## 9. 数据来源等级（S1–S5）

| 标记 | 含义 |
|:---|:---|
| **S1** | MACKORN 厂商技术参数表（NH/NS 系列） |
| **S2** | 国家标准 / 行业标准 |
| **S3** | 公开教科书 / 手册典型区间 —— **共识值，未逐条引用具体版本页码** |
| **S4** | MACKORN 工程经验区间 —— **非文献值** |
| **S5** | 现场实测（须标注工况） |
| **INTERP** | 表格插值（说明落在哪两列之间） |

**读取纪律**：看到 S3 要知道它是共识值不是精确值；看到 S4 要知道它是经验不是标准；看到 INTERP 要知道误差随插值距离增大。
