## 一、⚠️ 必须用【经典 token】

这是本次实测的重要发现：

| token 类型 | 推自己的仓库 | 回**别人仓库**的评论 |
|:---|:---|:---|
| **经典** `ghp_...` | ✅ | ✅（需 `public_repo` 或 `repo`） |
| **细粒度** `github_pat_...` | ✅ | ❌ **不行** |

**原因**：细粒度 token 只能授权给你**有权限的仓库**；
而我们不是 `awesome-dsh-plugin` / `punkpeye` 那两个仓库的协作者，
所以无法给它授权 → 回评论会 403。

### 创建经典 token（30 秒）

```
https://github.com/settings/tokens/new

Note:      mackorn-finish
Expiration: 7 days
Scopes:    ✅ public_repo        ← 只勾这一个就够
           （如果你还想改自己的仓库设置，可加 repo）

→ Generate token → 复制 ghp_ 开头那串
```
