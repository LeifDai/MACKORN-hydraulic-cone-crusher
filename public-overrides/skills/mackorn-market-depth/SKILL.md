# 市场纵深分析方法（公开版）

> 本公开版提供**方法**，不提供任何厂商内部价格或竞品评价结论。
> 竞品数值请以各厂商公开样本为准填入；价格请向 MACKORN 商务确认。

## 1. 五维取证框架（每维必须先取证再打分）

| 维度 | 要回答的问题 | 需要的证据 | 打分口径 |
|:---|:---|:---|:---|
| 行业 | 市场由谁构成、集中度如何、我方在哪一梯队 | 市场规模与增速、CR_N、梯队结构、下游资本开支周期 | 增速 >8% 且 CR10>0.6 → 5 分；3-8% → 3 分；<3% → 1 分 |
| 技术 | 技术路线是否收敛、我方差距在哪 | 路线图、能耗/可用率/寿命硬指标、关键材料与控制、专利位置 | 有硬指标可对标且达标 → 5 分；仅定性描述 → 2 分 |
| 时效 | 现在处于导入/成长/成熟期，投入是不是时候 | 成熟度阶段、近 24 个月落地项目、渗透率、政策窗口 | 已有规模化工业应用 → 5 分；仅实验室/中试 → 2 分；无近期落地 → 1 分 |
| 经济 | 投多少、多久回本、吨成本变化 | CAPEX 分项、OPEX（电耗/衬板/人工）、回收期、吨矿成本 | 回收期 <12 月 → 5；12-24 → 4；24-36 → 2；>36 → 1 |
| 可操作 | 现场能不能马上干、停机多久 | 改造窗口、施工吊装条件、备件可得性、技能门槛 | 不停机/短停机 → 5；需大修窗口 → 2；需重建 → 1 |

调用 `mackorn_market_intel`，把五维证据与分数传入 `scores`，得到加权得分与推进结论。

## 2. 破碎效率核心杠杆链（谈技术时的统一叙事）

```
均匀布料 → 速度均匀化 → 磨损稳定 → 模数恒定 → 料层密度稳定 → 破碎效率提升
  Φ≥0.95     梯度削平      CV≤0.10     M∈[4.0,4.5]     φ≤0.30        产量↑ / kWh/t↓
```

按链条逐环节给证据，不要只喊结论。配套工具：`mackorn_mcfm_analysis`、`mackorn_wear_design`、
`mackorn_grading_porosity`。

## 3. 竞品对比框架（数值请自行按公开样本填写）

`mackorn_market_intel` 返回的 `competitors.matrix` 只给**对比维度**：

技术路线 / 功率范围 / 控制系统 / 交货周期 / 备件供应 / 适用客户

公开产品线：Metso（HP/GP 系列，芬兰）、Sandvik（CH/CS/CG 系列，瑞典）、
Terex（T/TC 系列，美国）、thyssenkrupp（德国）。
具体功率、产能、控制配置请以各厂商**公开样本**为准填入，本插件不代替使用者做竞品评价。

## 4. 引用纪律（最重要）

1. **参考价 ≠ 报价。** 任何第三方或历史资料中的"参考价"都不能作为报价依据；
   MACKORN 报价一律走商务确认。
2. **每个维度结论必须能指到可核查证据**（报告页码 / 公开样本 / 实测记录）。
3. **同一指标多来源冲突时并列保留 + 标注统计边界**，不要合并成一个数，
   更不要私自取平均。
4. **研究样本数字必须标注时点、样本量与地域口径**，否则会被当成标定值误用。
5. 结论中显式区分：**硬数据 / 经验推断 / 空缺**。

## 5. 已知的数据缺口（公开版如实声明）

- 循环负荷系数与筛分效率的**厂家标定值**：无，现用工程经验区间
- 除铁器、除尘器价格：无
- 安装调试绝对金额：无
- 全系列偏心距：无
- NH600/NH700/NH860/NH865/NH890/NH895 与 NS 全系的**腔型×CSS 详表**：无（仅 NH200/300/400 有）

以上缺口在工具输出中一律返回 `null` 并进入 `warnings`，不会用默认值冒充。
